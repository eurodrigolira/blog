Salve Salve Pessoal!

Foi liberada uma nova versão do Oracle VM, a versão 3.4.3.

A nova versão oferece novos recursos, atualizações de segurança e correções de bugs.

**Capacidade de executar o Microsoft Windows Server Failover Clustering (WSFC) com o Oracle VM Windows PV Driver 3.4.2**

**Funcionalidade RAID melhorada, com suporte para dispositivos RAID de software.**

**Desempenho do Manager e melhorias de suporte, incluindo:**

**Conclusões de trabalhos mais rápidas.**

**Tempo reduzido para operações de atualização de armazenamento.**

**Suporte aprimorado para múltiplas conexões simultâneas ao CLI.**

**Processo de inicialização UEFI PXE simplificado.**

**Atualização do Unbreakable Enterprise Kernel Release 4 e atualizações para outros pacotes.**

Atualizações de segurança para componentes de gerenciamento e pacotes de servidor .
