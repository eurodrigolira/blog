Salve Salve Pessoal!

Nova versão do **ESXi Embedded Host Client,** **versão 1.32.0**.

Se você está com a versão **1.31.0**, logo que logar no ambiente será exibida uma tela informando sobre a nova versão, basta clicar em **Update.**

Se você estiver usando versões anteriores, verifique os posts anteriores sobre o **ESXi Embedded Host Client** para verificarem as formas de atualização.

[![](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-11-06-08.50.35-1024x499.png)](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-11-06-08.50.35.png)A URL com o endereço do **.vib** é preenchida automaticamente.

[![](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-11-06-08.51.11-1024x498.png)](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-11-06-08.51.11.png)Clique em continue.

[![](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-11-06-08.51.31-1024x493.png)](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-11-06-08.51.31.png)Atualização realizada com sucesso.

[![](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-11-06-08.51.56-1024x501.png)](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-11-06-08.51.56.png)Agora só sair do sistema e logar novamente.

Até a próxima!
