Salve Salve Pessoal!

Bem to aqui para falar de mais um plugin para segurança do wordpress, é o **WP Security Scan**.

Este é sem duvida um dos melhores plugins free que existe para wordpress. Ele ajudara você a manter as boas praticas de segurança, ele faz uma varredura no site wordpress atras de vulnerabilidades e depois lhe fornece um relatório detalhado de tudo que esta vulnerável, e os pontos onde devem ser corrigidos. Uma das grandes vantagens desse plugin é que ele além de fazer uma analise de seus diretórios ele também analisa toda a sua base de dados atras de vulnerabilidades.

Pois bem pessoal, baixem e divirtam-se como mais essa dica de segurança para wordpress, até a próxima.

Download do Plugin: [http://wordpress.org/plugins/wp-security-scan/](http://wordpress.org/plugins/wp-security-scan/)
