A Oracle anunciou hoje uma solução para backups de maquinas virtuais oficial e gratuita, o **ovm-bkp v1.0**.

É um utilitário que realiza backup das maquinas virtuais no **Oracle VM 3.4**, versões anteriores infelizmente não são suportadas :(

Segue abaixo algumas features do utilitário:

**Backup**

**Restore**

**Lista os backups disponíveis**

**Apaga um backup especifico**

**Backup do arquivos de configuração da VM**

**Logs das operações**

**Etc...**

Logo mais escreverei posts explicando como instalar e utilizar o utilitário, para maiores informações, acessem o link abaixo:

[ovm-bkp v1.0: Backup Utilities for Oracle VM 3.4](https://blogs.oracle.com/virtualization/ovm-bkp-v10%3a-backup-utilities-for-oracle-vm-34)
