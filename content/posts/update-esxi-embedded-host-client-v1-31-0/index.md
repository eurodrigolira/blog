Salve Salve Pessoal!

Nova versão do **ESXi Embedded Host Client,** **versão 1.31.0**.

Se você está com a versão **1.29.0**, logo que logar no ambiente será exibida uma tela informando sobre a nova versão, basta clicar em **Update.**

Se você estiver usando versões anteriores, verifique os posts anteriores sobre o **ESXi Embedded Host Client** para verificarem as formas de atualização.

[![](images/ESXI-02.eticons.local-VMware-ESXi-Mozilla-Firefox-2018-07-25-09.04.46.png)](images/ESXI-02.eticons.local-VMware-ESXi-Mozilla-Firefox-2018-07-25-09.04.46.png)

A URL com o endereço do **.vib** é preenchida automaticamente.

[![](images/ESXI-02.eticons.local-VMware-ESXi-Mozilla-Firefox-2018-07-25-09.05.56.png)](images/ESXI-02.eticons.local-VMware-ESXi-Mozilla-Firefox-2018-07-25-09.05.56.png)

Clique em continue.

[![](images/ESXI-02.eticons.local-VMware-ESXi-Mozilla-Firefox-2018-07-25-09.06.15.png)](images/ESXI-02.eticons.local-VMware-ESXi-Mozilla-Firefox-2018-07-25-09.06.15.png)

Agora faça Logout e recarregue a página, depois logue novamente e verifique a versão.

[![](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-07-25-09.13.59.png)](images/ESXI-01.lab_.local-VMware-ESXi-Google-Chrome-2018-07-25-09.13.59.png)Atualizado com sucesso!

Até a próxima! :D
