Salve Salve Pessoal!

Como o título do post já diz, vamos começar a desmistificar o Slackware :D

Em alguns grupos de whatsap e telegram que participo, sempre existem discussões quanto ao uso do Slackware, seja em ambientes de desktop ou em ambientes de servidor.

Normalmente as pessoas reclamam que é muito difícil de configurar, que não tem sistema de gerenciamento de pacote, alguns até pensam que o projeto não está mais ativo. :P

Bem, para começar o projeto está ativo e bem vivo, recebe atualizações constantes, podemos verificar isso dando uma olhada no changelogs do projeto.

[http://www.slackware.com/changelog/](http://www.slackware.com/changelog/)

Não é porque um sistema operacional não muda de versão constantemente, que quer dizer que o projeto foi abandonado. ;)

A minha intenção é fazer uma serie de post, falando desde a instalação a configuração de serviços (DHCP, DNS, NFS, SMB, Docker, etc) e como usar o Slackware como desktop sem maiores problemas.

Não tenho a intenção de entrar em discussão sobre qual distribuição é melhor ou pior, cada pessoa tem seu gosto e sua preferência.

Minha proposta é mostrar para vocês que é possível utilizar o Slackware tanto em servidores quanto em desktop.

Acesse também o grupo de usuários brasileiros no telegram.
