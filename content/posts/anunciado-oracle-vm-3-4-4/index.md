Salve Salve Pessoal!

Lançado o Oracle VM 3.4.4, entre as atualizações de segurança que já é normal, podemos citar as seguintes novidades nessa nova versão:

Suporte ao Windows Server 2016 e CentOS

Dom0 para Oracle VM Server atualizado para a atualização do Enterprise Kernel Release 4 Update 4

Suporte a processadores Skylake

Familia de processadores Intel® Xeon® E3 v5, Intel® Xeon® Platinum 8100, Intel® Xeon® Gold 6100, Intel® Xeon® Gold 5100, Intel® Xeon® Silver 4100 and Intel® Xeon® Bronze 3100

Adição do pacote:

network-scripts-vxlan

Atualização dos pacotes:

device-mapper-multipath-libs-0.4.9-100.0.3.el6.x86\_64

device-mapper-multipath-0.4.9-100.0.3.el6.x86\_64

kpartx-0.4.9-100.0.3.el6.x86\_64

libgudev1-147-2.73.0.1.el6\_8.2.x86\_64

libudev-147-2.73.0.1.el6\_8.2.x86\_64

udev-147-2.73.0.1.el6\_8.2.x86\_64

Entre outras melhorias de perfomance, segurança e resolução de bugs.
