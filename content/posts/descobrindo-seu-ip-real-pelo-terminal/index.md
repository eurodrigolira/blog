Salve Salve Pessoal!

Hoje vou dar uma dica bem simples, como descobrir seu IP real pelo terminal.

Existe um site chamado **ifconfig.me,** que quando acessamos ele pelo navegador, ele nos informa o nosso IP Real.

Mas utilizando o curl, ele também informa o nosso endereço IP, existem outras possibilidade dependendo dos parâmetros que utilizarmos, dessa forma esse site pode ser muito útil para scripts e etc.

A sintaxe é básica:

```
# curl ifconfig.me
```

Ele mostrará seu IP.

No site informa todas as possibilidades possíveis, acesse pelo link abaixo:

[ifconfig.me](http://ifconfig.me/)
